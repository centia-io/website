# Privileges

Privileges are the table-level access control in Centia.io. A [sub-user](./users.mdx) owns its own schema and can do anything there, but has no access to tables in other schemas until a privilege is granted. The super-user can grant `read` or `write` on any table, and a sub-user can grant privileges on tables in the schemas it owns, so a team can share a dataset without sharing credentials.

Privileges are enforced everywhere a table is reached: the [SQL API](./statement.mdx), GraphQL, the [Feature API](./features.mdx), [Realtime](./realtime.mdx) subscriptions and the [OGC services](./ogc/services.mdx). They answer whether a user may touch a table; to restrict which rows the user sees, combine them with [rules](./rules.mdx). Privileges granted to a group are inherited by its members, as described under [groups and inheritance](./users.mdx#groups-and-inheritance).

## Set privileges for a user on a table

By default, a sub-user has `none` privilege on tables outside their own schema. Privileges can be set explicitly to `none`, `read`, or `write`.

- `none`: The sub-user cannot run statements on the table.
- `read`: The sub-user can run `select` statements on the table.
- `write`: The sub-user can run `select`, `insert`, `update`, and `delete` statements on the table.

<Tabs>
    <TabItem value="webapp" label="Web App">
        ![Set privileges in the Centia Web App](/img/screenshots/webapp-placeholder.svg)
    </TabItem>
    <TabItem value="http" label="HTTP" default>

        ```http title="Setting a single privilege"
        PATCH https://api.centia.io/api/v4/schemas/rockhall/inductees/privileges HTTP/1.1
        Content-Type: application/json
        Authorization: Bearer abc123

        {
            "subuser": "alx",
            "privilege": "write"
        }
        ```
        ```http title="Setting multiple privileges"
        PATCH https://api.centia.io/api/v4/schemas/rockhall/inductees/privileges HTTP/1.1
        Content-Type: application/json
        Authorization: Bearer abc123

        [
            {
                "subuser": "alx",
                "privilege": "write"
            },
            {
                "subuser": "slash",
                "privilege": "write"
            }
        ]
        ```

    </TabItem>
    <TabItem value="cli" label="CLI">

        ```bash
        centia privilege set
        ```

    </TabItem>
</Tabs>

## Get privileges

<Tabs>
    <TabItem value="webapp" label="Web App">
        ![View privileges in the Centia Web App](/img/screenshots/webapp-placeholder.svg)
    </TabItem>
    <TabItem value="http" label="HTTP" default>

        ```http title="Request"
        GET https://api.centia.io/api/v4/schemas/rockhall/inductees/privileges HTTP/1.1
        Accept: application/json; charset=utf-8
        Authorization: Bearer abc123
        ```

        ```json title="Response"
        [
            {
                "subuser": "alx",
                "privilege": "write"
            },
            {
                "subuser": "slash",
                "privilege": "write"
            }
        ]
        ```

    </TabItem>
    <TabItem value="cli" label="CLI">

        ```bash
        centia privilege get
        ```

    </TabItem>
